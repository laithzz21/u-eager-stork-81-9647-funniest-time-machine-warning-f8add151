## The entry

> WARNING: Do not meet yourself. He knows what you did, and he's already warned you about this.

The warning is self-defeating in exactly the way a time machine would be: your future self has already tried to warn you — which means the warning you're reading is the failed attempt. Meeting yourself is the one thing the label forbids, and the label itself is proof it already happened.

## What this does

`main.py` (Python 3.13, stdlib only, deterministic — no network, clock, or randomness) validates the entry (single line, 1–120 characters, starts with `WARNING:`, no leading/trailing whitespace or doubled spaces), prints it to stdout, and also writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, falling back to `./output/entry.txt` if `/output` is not writable), verifying the written file by reading it back (exact text and length). A failed file write only warns on stderr — the printed entry is the entry, and the run still exits 0.

## How to run

```bash
python3 main.py
```

Exits 0 on success. The entry text is printed to stdout and written to `entry.txt` in the output directory.
